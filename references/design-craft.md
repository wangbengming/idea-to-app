# 设计工艺手册（商业级设计的"加法"）

本手册与 `design-baseline.md`（防 AI 味基线）构成设计部的**双册制**：基线册管"不许做什么"（防丑），工艺册管"应该怎么做"（产美）。只守基线的设计 = 干净但平庸；只追工艺不守基线 = 花哨但廉价。两册都要过。

方法论源自对商用设计系统的三条公理（参考 [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的产品推理库——192 类产品的风格/配色/字体/反模式档案，本机已装，联动方式见第八节）：

> **商业级 ≠ 更多的装饰，而是三样东西：**
> 1. **系统感**——所有页面像同一个产品做的（令牌一致、深度一致、动效一致）；
> 2. **身份感**——这套界面只属于这个产品和行业，换个内容就违和（风格定位先行）；
> 3. **完成度**——任意挑一个角落（空态、报错、按住按钮、暗色、手机）都有设计过的答案。
>
> "大学生画图"的观感 = 有想法没系统、有装饰没身份、有正面没细节。

**设计三重奏（收口锚点）**：审美、交互、体感三样都过，设计才算完成——**重审美**（风格定位 + 令牌 + 构图工艺，本册与基线册）；**重交互**（流程节点走查 + 操作成本预算 + 五态四境 + 撤销与反馈）；**重体感**（响应跟手 + 无系统弹窗 + 加载有骨架 + 动画只动 transform/opacity，见 tech-recipes「体感与交互工艺」）。任何一样被走查判"不过"，整个 02 不算过。

## 一、五步法总纲（写 02 的固定顺序）

| 步 | 产出（落进 02 哪节） | 一句话标准 |
|---|---|---|
| ① 风格定位 | 「风格定位」节 | 3 个气质形容词 + 1 个风格族 + 按产品类型列出反模式，能说出"为什么是它" |
| ② 设计令牌 | 「设计令牌」节 | 五套令牌（色彩/字体/间距/深度/动效）全部给具体值，全站只引用令牌 |

| ⑤ 按优先级审计 | 「体验自查」「基线自查」节 | 按第十节顺序过一遍，先命中的先修 |

## 二、第一步·风格定位：风格族谱

**规矩：先选族，再动笔。** 每族是一整套预设（圆角/阴影/间距/动效的取向），选了族就全站贯彻；混族 = 拼贴感，是最典型的业余标志。

按项目类型选（同族内按用户气质微调）：

### 工具类（tool）

| 风格族 | 气质 | 令牌特征 | 别用在 |
|---|---|---|---|
| **瑞士极简**（默认） | 克制、秩序、快 | 圆角 0~8px、无阴影或极浅、强调色仅一个、网格排版 | 儿童娱乐、喜庆场景 |
| **柔和拟物** | 温和、亲切、健康 | 圆角 8~12px、单层柔和阴影、200~300ms 动效、色彩分层清晰 | 极简强迫症项目、性能敏感 |
| **微交互** | 灵动、有回应感 | 50~100ms 微反馈、状态动画（成功/出错）、按压/滑动都有回应 | 纯桌面不看触感的项目 |
| **纸墨阅读** | 安静、专注 | 米白底 #FDFBF7、近黑字 #1A1A1A、细边框 #E0E0E0、零动效 | 游戏、营销、暗色依赖 |

### 后台类（admin）

| 风格族 | 气质 | 令牌特征 | 别用在 |
|---|---|---|---|
| **数据密度**（默认） | 专业、高效 | 网格间距 8px、卡片内边距 12px、小字号 12px、行高 36px、侧栏 240px | 给外部客户看的展示页 |
| **分层卡片** | 清晰、现代 | 四级阴影阶梯（见 3.4）、层级靠深度表达 | 印刷风布局、低端设备 |
| **企业规范**（Fluent 风） | 稳重、像正经软件 | 标准控件、明确焦点环、克制动效、surface/on-surface 语义色 | 与微软气质冲突的品牌 |

### 商用前台（front）——气质权重最高，按行业选族

| 风格族 | 适合的行业/气质 | 令牌特征 | 别用在 |
|---|---|---|---|
| **自然有机** | 餐饮、生鲜、烘焙、花店、健康 | 大地色（绿 #228B22 / 棕 #8B4513 / 米白底）、圆角 24px、柔和阴影 0 8px 32px | 科技、游戏、工业风品牌 |
| **暖调手作** | 手工艺品、民宿、茶室、暖食 | 陶土 #C67B5C、沙米 #D4C4A8、软奶油底 #F5F0E1、橄榄绿点缀、微纹理 | 科技创业、夜生活、金融 |
| **编辑部杂志** | 摄影作品、律所、专栏、内容站 | 非对称网格、衬线正文 + 粗黑标题、大图、首字下沉、拉引言 | 后台、表单密集、商品目录 |
| **夸张极简** | 建筑、设计工作室、高端品牌 | 特大标题 clamp(3rem,10vw,12rem)/900 字重、超大留白 8rem、黑白 + 单强调色 | 商品目录、表单、数据密集、老年用户 |
| **便当格** | 产品展示、团队介绍、功能总览 | 网格间距 16px、大圆角 24px、浅灰底 #F5F5F7、悬停微缩放 1.02 | 密集表格、文字-heavy |
| **活力色块** | 儿童教育、活动、年轻品牌 | 色块拼排、间距 48px+、大字 32px+、4~6 个鲜艳色 | 金融、医疗、政府、中老年用户 |
| **包容普惠** | 政务、医疗、教育、社区服务 | 对比度 7:1、最小字号 16px、焦点环 3~4px、触摸目标 44px+ | ——（普遍适用的底线族） |

**定位话术**（写进 02「风格定位」节）：
> 本项目气质：**温暖、家常、值得信赖**（3 个形容词）。选族：**自然有机**。理由：社区烘焙店的客人期待"出炉的面包感"，大地色 + 大圆角 + 柔阴影传达温度；禁用科技蓝紫与锐利直角（与食物气质冲突）。本行业反模式：食物照片模糊、营业时间难找（见第七节）。

## 三、第二步·设计令牌：五套令牌一次定死

全站样式**只准引用令牌**（02 落成 `:root` CSS 变量表）。令牌定得越狠，实现越不会走样。

### 3.1 色彩令牌（16 个语义位，不是"1 主色 + 1 强调色"）

| 令牌 | 作用 | 业余 vs 商业 |
|---|---|---|
| `--c-primary` / `--c-on-primary` | 主色 / 主色上的文字 | 每个色都配"它身上的字该什么色"，不是事后凑 |
| `--c-secondary` / `--c-on-secondary` | 次级色 / 其上文字 | 次级操作、选中态 |
| `--c-accent` / `--c-on-accent` | 强调色（一屏一个）/ 其上文字 | 只给最重要的一个动作 |
| `--c-bg` / `--c-fg` | 页面底 / 正文 | 底和字是**一对**，不是各定各的 |
| `--c-card` / `--c-card-fg` | 卡片底 / 卡片文字 | 卡片与页面底必须有可感知的层次差 |
| `--c-muted` / `--c-muted-fg` | 弱化底（分隔/次级面）/ 弱化文字 | 次要信息全走这对，不许另造灰 |
| `--c-border` | 边框/分隔线 | 全站唯一的边框色 |
| `--c-danger` / `--c-on-danger` | 危险色 / 其上文字 | 删除、报错专用，禁挪作他用 |
| `--c-ring` | 焦点环色 | 键盘导航的可见性，不是装饰 |

**派生规则（从一个气质推出整套色板）：**
1. **定主色**：从行业气质来（食物→暖棕陶土，医疗→青绿，金融→藏蓝，儿童→明黄橙）。用色板时优先从产品行业找，不凭感觉；
2. **中性灰随主色染色**：暖色板配微暖灰（灰里带一点棕），冷色板配微冷灰（灰里带一点蓝）。**纯中性灰 + 暖主色 = 大学生画图最典型的色味分离**；
3. **60-30-10**：60% 背景/中性面、30% 次级面/卡片、10% 主色/强调色。数一下页面里彩色面积，超了就是滥用；
4. **每对前景/背景过 4.5:1**（大字 3:1）；正文用近黑（如 #1F2328）不用纯黑 #000，纯黑在浅底上过刺；
5. **状态色**（成功/警告/危险）出现时**必带图标或文字**，不许只靠颜色表意；
6. 深色主题（如需要）：不是反色——背景提亮一档、彩色整体**降饱和提亮度**，每对重新测对比度。

**成品示例**（社区烘焙店，暖棕派生，已验对比度）：
`--c-primary:#92400E（暖棕）--c-on-primary:#FFF --c-bg:#FFF7ED（奶油白）--c-fg:#78350F（深咖，非纯黑）--c-card:#FFF --c-muted-fg:#8A6D55（暖灰棕）--c-border:#FDE8D0 --c-accent:#C2410C --c-danger:#DC2626`
注意灰阶全部带暖——这就是"系统感"在色彩上的落点。

### 3.2 字体令牌（系统字体栈语境的"配对"）

零框架 + 禁外链字体 ≠ 放弃字体设计。**性格靠三件事：字族反差、字重层级、字号反差。**

- **正文栈**（默认）：`-apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- **标题衬线栈**（编辑部/手作/高端族选用）：`Georgia, "Songti SC", "STSong", "SimSun", serif`——只用于大标题/引言，正文禁止
- **数字金额**：`font-variant-numeric: tabular-nums`（表格、账目、价格必开，数字才对齐）
- **字重层级（三层，全站只用这三个值）**：700 大标题 / 500 小标题·按钮·标签 / 400 正文。中文字重低于 400 显虚、900 显糊，都不用
- **字阶（比率 1.25，最多 5 档）**：12（辅助）14（次级）**16（正文基准）** 20（小标题）25~31（大标题）。中老年画像整体上移：基准 18px，按钮高度 ≥48px
- **行高与行长**：正文 1.6~1.75、标题 1.2~1.3；中文一行 30~45 字，超了就加栏宽或收容器
- **字距**：中文一律不动 `letter-spacing`；英文小标签（如 "NEW"）可用 `+0.05em` + 500 字重 + 小字号做"眉题"效果

### 3.3 间距令牌（三档密度，按类型选）

| 档 | 适用 | 令牌值 |
|---|---|---|
| 宽松 | front 营销页 | sp-1:24 / sp-2:32 / sp-3:48 / sp-4:64 / sp-5:96 |
| 标准（默认） | tool / 常规页 | sp-1:8 / sp-2:16 / sp-3:24 / sp-4:32 / sp-5:48 |
| 密集 | admin 后台 | sp-1:4 / sp-2:8 / sp-3:12 / sp-4:16 / sp-5:24 |

垂直节奏三层制：**组件内** 8~12、**组件之间** 16~24、**区块之间** 32~48——同级间距必须相等，间距本身就在表达信息层级。

### 3.4 深度令牌（阴影/高度的固定阶梯）

全站只用这五档，**禁随手发明第六种阴影**：

| 层 | 用途 | 阴影参考值 |
|---|---|---|
| el-0 | 页面底 | 无 |
| el-1 | 卡片 | `0 1px 3px rgba(0,0,0,.1)` |
| el-2 | 悬停/下拉 | `0 4px 6px rgba(0,0,0,.1)` |
| el-3 | 弹窗/抽屉 | `0 10px 20px rgba(0,0,0,.12)` |
| el-4 | 轻提示 toast | `0 20px 40px rgba(0,0,0,.15)` |

- 浅色主题靠阴影 + 边框一起分层（1px `--c-border` + el-1 是最稳的卡片配方）；
- 深色主题**靠表面色提亮分层**（一层比一层亮），阴影几乎不可见，别硬靠阴影；
- 圆角全站一个值（或"小组件 8 / 卡片 12"两个值），三个值以上 = 没系统。

### 3.5 动效令牌（三档预算，按产品气质选一档）

| 档 | 适用 | 预算 |
|---|---|---|
| **克制**（tool 默认） | 工具、后台 | 只有交互反馈：100~200ms，无入场动画 |
| **标准**（admin/front 默认） | 内容站、常规前台 | 反馈 + 入场：150~250ms ease-out，列表错峰 30~50ms |
| **表现**（front 品牌页慎用） | 营销页局部 | + 滚动叙事/大字动效，一页最多 1~2 处，每个动效能回答"它表达了什么" |

**通用铁律**（与基线册同源）：只动 `transform/opacity`；退场比进场快约 1/3；动画必须可被打断（点了别处立即到终态）；`prefers-reduced-motion` 一行兜底；按压反馈 = `scale(0.97)` 或亮度变化，80~150ms。

## 四、第三步·布局模式：用成熟模式，不从零发明

商业页面长得"专业"，八成是因为用了被验证过千百遍的区块模式。每页在 02 里注明用的哪个模式。

### front 商用前台的区块库（按目的拼装）

| 区块 | 什么时候用 | 商业要点 |
|---|---|---|
| **Hero（首屏）** | 每页必有 | 3 变体：居中一句话型 / 左文右图型 / 全图打底型。首屏必须回答"这是干嘛的 + 跟我有什么关系"，一个主按钮，别放两个 |
| **信任条** | 有合作方/资质/数据 | 一行灰度小 logo 或三个数字（"500+ 服务家庭"），放 Hero 下方，给"敢信"的理由 |
| **特性卡** | 卖点 3~5 个 | 2×2 或三列卡，每卡：图标 + 一句话 + 不解释。超过 5 个砍到 5 个 |
| **社会证明** | 有真实评价/案例 | 评价放 CTA **前**：真人头像 + 姓名 + 一句话。没有真的就别编——编的更减分 |
| **菜单/服务价目** | 餐饮/服务业 | 价格透明是转化率本身；图片必须真实清晰（餐饮第一死罪是照片差） |
| **信息条** | 门店类必备 | 营业时间/地址/电话，手机端**一屏内可达**，电话可点击直接拨 |
| **FAQ** | 有预约/价格的生意 | 手风琴折 5~8 条，解决"怕麻烦"的顾虑 |
| **最终 CTA + 页脚** | 每页收尾 | 一句话 + 一个按钮收束；页脚放联系方式/备案，不出彩但必须整洁 |

### admin 后台的信息架构
- 固定骨架：侧导航（240px）+ 顶栏 + 内容区；导航分组 ≤5 组、每类角色只渲染有权限的项；
- 列表页三件套：搜索/筛选在内容区顶部一行、批量操作收进"选中后出现"的工具条、行内操作"改"直接进、"删"二次确认；
- 表单页：一屏一个任务；分组用带标题的分区；保存回列表并高亮新行。

### tool 工具页的动线
- **核心动作第一屏可完成**：主按钮占视觉重心，拇指区（手机下半屏）放高频操作；
- 次要功能（设置/备份/关于）收进右上角，不跟主动作抢注意力；
- 一屏一个强调色 = 主按钮的颜色。别的全中性。

### 响应式
断点 375 / 768 / 1024 / 1440，手机优先写起。手机端三件套：多列变单列、导航收进抽屉、表格变卡片。`100dvh` 替代 `100vh`，固定底栏加 `env(safe-area-inset-bottom)`。

### 构图工艺（反模板感——布局的"用法"，AI 味的结构源头）

模式库给的是砖，怎么砌才不像模板。AI 味一半来自颜色（基线册管），另一半来自**结构同质**——每页都是"居中大标题 + 三等分卡片阵列 + 页脚"的标准拼装。一个方法 + 六条清单：

**真实参考法（动笔前必做，落进 02「趋势侦察」）**：用 WebSearch/WebFetch 找 2~3 个**同行业真实网站**（生意做得像样的那种，不是设计趋势文章），逐个记三件事：URL、它的哪一处**结构**值得学（如"菜单页整行大图 + 价格右对齐大字"）、转化到本项目哪一页怎么用。"当前流行大字号、卡片式分区"这类**泛词不算参考**——泛词产出的就是模板。ui-ux-pro-max 给的是色板与令牌起点，**不是构图答案**；构图只从真实网站来。

**实时审美条款**：参考必须**当下活着**——确认站点仍在运营、界面是当前版本（近一两年有过改版的更好）； archived 截图、已死的案例站、明显过时的手法（拟物按钮、老式渐变横幅）不算实时审美，视同 AI 味处理。审美跟时间走：ui-ux-pro-max 的推理库本身就是持续更新的，先跑它再定，别只凭模型记忆里的"审美"。

**反模板构图清单（每页自查，02 交互节逐条引用）**：
1. **三等分同构卡片阵列不当默认骨架**——三列特性卡、三列图文、三列定价，是 AI 模板味最重的一格；换成 2+1 主次、1 大带 2 小、横向滚动或干脆表格化。
2. **居中标题堆叠每页最多一次**——"大标题 + 副标题 + 按钮"整套居中出现第二次就是模板；下一屏换左对齐/分栏/侧标签。
3. **至少一处打破均质**——跨列大图、全宽色带、错位两栏、超大留白任选其一，让页面有"重心"而不只是"排列"。
4. **字号对比要狠**——大标题 ≥ 正文字号的 2 倍并拉开字重（700 对 400）；对比温和 = 平 = 模板感。
5. **区块节奏不等高**——相邻区块的高度/密度/底色要有疏密变化；等高等距的"分层蛋糕"是排列，不是设计。
6. **真实内容测试**——线框与设计稿里的文字一律用**真实业务内容**（真实店名/菜品/价格/数字），禁"这里放标题""XX 介绍"占位；空洞文案本身就是 AI 味，且只有放上真实内容，间距与字号的问题才会暴露。

---

## 五、第四步·细节密度：状态完备性

业余和商业的分水岭在"没画出来的地方"。

**每个可交互组件五种状态**：默认 / 悬停（桌面）/ 按下 / 禁用（降透明度 + 禁指针 + 语义属性）/ 加载中（按钮转圈并禁点）。
**每块数据四种境况**：常态 / **空态**（温度话 + 一个明确按钮）/ **错态**（哪里错 + 怎么改 + 重试）/ **加载**（骨架形状 = 内容形状，不是转圈）。

组件速查：
- **按钮**：一屏只有一个实心主按钮；次按钮描边款；文字按钮给纯文字操作。危险按钮红色且与普通按钮**隔开距离**；
- **表单**：label 常显（placeholder 不是 label）；校验在失焦时做，别在敲键时报错；错误红字出现在字段正下方并 `aria-describedby` 关联；密码框给显隐切换、不禁粘贴；
- **卡片**：整卡可点时 hover 抬升（el-1→el-2）+ 指针手型；卡内信息分层（主信息 20px/500，元信息 14px/muted 色）；
- **列表**：分隔线或留白分组二选一，数据表格用斑马纹；行操作统一放行尾；
- **图标**：**单一家族、同一线粗（1.5 或 2px）、同层级同一填充风格**；表情符号当图标 = 直接判缺陷；自绘 SVG 或宽松许可证内联，语义贴切，图标按钮必带 `aria-label`。

## 六、第五步·按优先级审计（走查顺序）

发现问题时**按这个顺序修**——前面的挡住后面的，再美观也白搭：

1. **无障碍**：对比度、焦点环、aria、键盘可达、不只靠颜色表意
2. **触摸与交互**：44px 目标、间距 8px+、加载反馈、悬停不能是唯一入口
3. **性能**：图片压没压、动效有没有引起重排、大列表分页
4. **风格一致性**：全站一个族、一套令牌、一个图标家族、阴影只用阶梯值
5. **布局与响应式**：375px 不破版、无横向滚动、断点表现
6. **排版与色彩**：字阶/字重/行长/对比度、60-30-10
7. **动效**：预算档位、transform/opacity、reduced-motion
8. **表单与反馈**：label、就近校验、错误文案质量
9. **导航**：位置全站一致、当前项高亮、返回可预期
10. **图表**（如有）：类型配数据、图例、悬停数值

报告缺陷沿用基线册的**三证明审计法**（合同/运行时/修正三证齐全）。

## 七、按产品类型的"懂行"反模式

全局 AI 味在基线册。这里按行业列"外行看不出、内行一眼假"的死穴，写 02 时**至少认领本项目的两条**并自查：

| 产品类型 | 一眼假的反模式 |
|---|---|
| 餐饮/门店 | 食物照片糊或用网图；营业时间/地址藏得深；菜单没价格 |
| 预约/服务 | 价格不透明（"到店详询"）；流程超过 3 步没有进度指示 |
| 管理后台 | 一屏塞多个主任务；表格不能排序；删除没有后果说明；保存后无任何反馈 |
| 单机工具 | 核心动作藏在菜单里；一打开就是"使用说明"；让用户注册（本地工具不需要） |
| 内容/作品展示 | 正文一行超过 45 字；图片无 alt；标题与正文无层级差 |
| 官网/SaaS | 默认深色主题 + 满屏动效（AI 味招牌）；特性罗列无重点；三等分同构卡片阵列当骨架；首屏说不清卖什么 |
| 儿童/教育 | 触摸目标 < 48px；文案用成人词汇；色彩刺眼无留白 |
| 中老年工具 | 正文 < 18px；按钮 < 48px；低对比灰字；危险操作只有一个确认 |

## 八、与 ui-ux-pro-max 技能联动（可用时必用）

本机装有 `ui-ux-pro-max` 技能（~/.agents/skills/ui-ux-pro-max），内含 192 类产品推理档案、50 个活跃风格、192 套语义色板、74 组字体搭配。**设计师动笔前先跑一次，把它的推荐作为定位与色板的起点**（它给的是专业库的答案，不是模型的感觉）：

```bash
python ~/.agents/skills/ui-ux-pro-max/scripts/search.py "<产品类型> <行业> <气质关键词>" --design-system -p "<项目名>"
```

**输出怎么用**：PATTERN→第四步的页面模式；STYLE→第二步的风格族定位；COLORS→16 个语义色令牌**直接抄进 02**（已验对比度）；TYPOGRAPHY→字族气质参考（本地化替换见下）；EFFECTS→动效档位；AVOID→第七节的行业反模式。

**本地化三替换（必做，机器红线）**：
1. **Google Fonts 链接 → 系统字体栈**：交付物禁外链，按 3.2 的映射换（圆润趣味→圆体优先栈；优雅衬线→Georgia/Songti 栈；专业现代→默认 sans 栈）；
2. **字号/间距按画像放大**：中老年画像基准 18px 起，别照抄它的 16px 默认；
3. **检查外链与版权**：它的示例若含 CDN/品牌素材，一律换成自绘 SVG / 本地资源。

技能不可用（无 Python/目录缺失）时，按本手册风格族谱 + 色彩派生规则手动定系统——**这正是本手册存在的意义**。
