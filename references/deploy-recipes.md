# 部署与发布手册（阶段 5：项目经理的竣工后动作）

本地竣工（G4 发版 + 全部积木块经用户查验）之后，应用已经能用。本手册是**可选升级**的决策与执行依据：给建议、讲代价、用户采纳才动手。

## 总则

1. **先本地竣工，再谈部署**：部署建议在交付复习之后提出，一次最多 3 个选项，用 AskUserQuestion 让用户挑；不采纳不推销。
2. **每一步说人话**：不出现"服务器/域名/HTTPS/端口"等词，说"放网上的地方""网址""加密连接"。涉及用户自己操作（注册账号、点哪个按钮）的步骤全程带教。
3. **讲清代价再动手**：花钱的（云服务器/域名）、数据离开用户电脑的（放到网上），必须先把"要花多少、数据会放到哪、谁能看到"讲明白，用户点头才执行。
4. **安全先行**：07-安全清单里的"严重/一般"缓解项全部 fixed 才允许对外部署；admin 类**公网部署默认劝退**（见下），除非用户明确接受升级成本。
5. **落盘与验收**：采纳的方案写成《部署方案.txt》（分步：点哪里/填什么/看到什么算成功）放进应用文件夹；部署完成后真实验收（换设备访问、定时任务真触发一次），把新用法写进《我的应用.md》。

## 按类型的部署选项

### tool 单机工具

| 选项 | 说什么 | 要点 |
|---|---|---|
| 换台电脑用 | "把整个文件夹拷过去就能用" | 提醒：localStorage 数据跟文件位置绑定，带数据走用"备份/恢复" |
| 分享给别人 | "发整个文件夹 + 使用说明" | 确认应用里没有夹带用户自己的私人数据 |
| 开机自启/定时 | 见 data 的定时方案 | 一般没必要，别为炫技加 |

### data 数据脚本

| 选项 | 说什么 | 要点 |
|---|---|---|
| 定时自动运行 | "让它每天凌晨自己跑，早上看结果就行" | Windows 任务计划程序：分步截图级指南（建基本任务 → 选程序 → 选 启动.bat → 设时间）；首次手动触发一次验收；窗口会闪现属正常（或改用 pythonw 隐藏窗口） |
| 输出自动送达 | "结果直接出现在你的文件夹/邮箱" | 邮件需用户自己的邮箱账号与授权码——只把"发什么、发到哪"讲清，凭证让用户自己填，不让用户把密码交给你 |
| 换电脑/给别人 | 同 tool | 输入输出文件夹结构别拆散 |

### admin 管理后台（方案 E）

| 选项 | 说什么 | 要点 |
|---|---|---|
| 自动备份 | "每天自动多存一份，丢不了" | 任务计划程序复制 data.db 到带日期的文件；与界面"备份数据"按钮双保险 |
| 同一 WiFi 开放 | "店里其他电脑和手机也能用了" | 改 `HOST = "0.0.0.0"` + Windows 防火墙放行该端口（分步指南）；教用户查本机 IP；提醒"这个网络里的人都能打开，账号还是一人一个" |
| 公网上线 | **默认劝退**："要花钱租一台网上的电脑，还要做一轮安全加固，建议先在店里用顺" | 用户坚持才做：云服务器 + 域名 + HTTPS（Caddy/certbot）+ 安全清单全绿 + 强密码/限速复核；明说"这一步以后做，今天先记录到'以后再说'" |

### front 商用前台

| 选项 | 说什么 | 要点 |
|---|---|---|
| 发布到网上 | "免费，顾客在任何地方都能打开" | 静态托管三选一（按用户情况推荐）：GitHub Pages / Netlify / 云对象存储；**账号注册在用户自己名下**、整站文件夹随时可搬走（部署自主性阶梯见 tech-recipes）；全程带用户注册与上传；发布前过一遍**上线检查清单**（下表） |
| 自己的网址 | "把网址换成你的名字（一年几十块）" | 域名注册由用户本人完成（实名与付款），你只指导绑定 |
| 后续改内容 | "以后改文字图片跟我说，改完再发一次就好" | 说明"发布"只是把文件夹搬上去，改内容很快 |

**上线检查清单**（front 发布前逐项过）：每页 title/描述；手机实机看一遍；图片压缩且本地；素材版权（用户素材/自绘/宽松许可）；电话微信按钮可点；404 行为；不收录任何用户隐私数据；整文件夹体积与首屏达标（性能预算见 tech-recipes）。

## 数据库与服务升级建议（技术负责人会诊）

- **SQLite 什么时候都够用**：单机/店内几人用、几万条以内——直接说"这个够用很多年，不用升级"。
- **出现这些信号才谈升级**：跨城市多人同时用、数据量到几十万条、需要多人同时写同一批数据不冲突。升级 = **换形态的新版本**（云数据库/云服务器），进"以后再说"版本主题，走正常迭代，**不现场改**。
- 用户问"数据会不会丢"：答"存在你自己电脑的文件里，备份做了就不会丢；真要防电脑坏掉，多备份一份到网盘/优盘"——不到必要时不主动把用户数据搬上云。

## 部署话术示例

竣工后给建议：

> 系统竣工啦！在电脑上双击就能用，这是最稳的用法。另外有三个可选的升级，要不要都行：① 每天早上自动备份数据；② 同一 WiFi 下手机也能打开这个系统；③ 把官网发布到网上，顾客在外面也能看（免费，要注册个账号，我全程带你操作）。想要哪个跟我说一声。

用户采纳后：

> 好，我把《部署方案.txt》放在文件夹里了，一共 5 步，每步都写清"点哪里、填什么、看到什么算成功"。你跟着做，卡在哪儿直接喊我。
